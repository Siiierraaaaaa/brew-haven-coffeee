## Project Overview

Brew Haven Coffee is a modern, responsive website created for a fictional specialty coffee shop. The goal was to design a welcoming online presence that encourages customers to visit the café while showcasing its menu, story, and atmosphere.

---

## Features

- Responsive Design
- Mobile Navigation
- Hero Banner
- Featured Coffee
- About Section
- Menu Preview
- Testimonials
- Contact Form
- Newsletter Signup
